# 引擎工坊：Windows 电脑独立试玩版

这是根据用户确认的 iOS《引擎模拟器》、调校数据和录屏独立编写的电脑试玩项目。它不是官方 Windows 版，也没有使用或反编译原应用的安装包或源代码。

## 在 Windows 上运行

1. 点击 GitHub 页面右上角 **Code → Download ZIP**，解压下载的文件。
2. 打开解压后的 `engine-lab` 文件夹。
3. 双击 `启动引擎工坊.cmd`。电脑需要安装 Node.js；无需安装 npm 依赖。
4. 应用会在默认浏览器打开，服务仅监听本机 `127.0.0.1:4328`。关闭页面后如需停止后台服务，可运行 `Stop-EngineLab.ps1`。

项目内包含三维库、音频素材及其许可信息，运行时无需访问外网。

## 项目内容

- 浏览器中的发动机调校、仪表、四冲程示意、三维机构和试车场。
- 从用户提供的调校备份整理出的参数库与导入器。
- 录屏对照版的录音颗粒处理及独立实现的声音控制。
- 使用说明、音频署名和 Three.js 许可。

## 实现边界

本项目按可见界面、用户提供的数据和录屏独立实现。三维机构是程序化示意，车辆动力与声音由本项目的简化模型计算，不代表真实车辆测试结果，也不保证与手机原作的界面、声音或数值完全一致。录音来源、许可和本项目的处理方式见 [音频素材与许可](engine-lab/音频素材与许可.md)。
