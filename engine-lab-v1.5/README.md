# 引擎工坊 1.5

独立浏览器引擎试玩程序。新增驾驶、发动机工坊、车辆三页，24个仪表，维护补给、速度诊断和可编辑传动/路面。

## 运行

使用已有 Node.js，在此目录运行：

```powershell
npm start
```

打开 http://127.0.0.1:4328/。也可双击“启动引擎工坊.cmd”。服务只监听127.0.0.1，运行素材均随程序保存。

最新内置V8可由左侧按钮载入；原机预测574PS/700N·m作为该配置的曲线约束，中间曲线、动力/温度/油耗/混音仍为独立实现。

## 文件范围

本目录包含程序、处理后的170组参数和必需音源/三维依赖。保留旧版目录，不替换原有文件。原始手机JSON、IPA、录屏、运行日志、验证记录没有上传。

原生备份导出按钮须先在本机通过“导入调校”导入原始备份后使用；本版调校保存和导出无需原始备份。已导入的文件只保留在当前本机浏览器，不会自动提交到GitHub。

`npm test` 运行随程序附带的50项测试；依赖私有原始备份的8项检查保留在本地工作目录。

音源署名与许可见 [音频素材与许可.md](音频素材与许可.md) 和 [CREDITS](audio/package/CREDITS.md)。本项目没有包含原作加密程序或声称恢复原生DSP。
