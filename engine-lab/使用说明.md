# 引擎工坊 · 电脑独立试玩版

当前为 1.2 录屏对照版。点击「载入录屏里的 Hellcat」，启动后按住 W 再松开，先试听本次重做的声音。右栏可切换录音颗粒／合成对照、车内／车外，并分别调节音量、收油爆音及增压声；这些声音选项单独保存在当前浏览器。圆形仪表下方可展开四冲程示意及实测声音波形。

双击同文件夹的 **启动引擎工坊.cmd**，会在默认浏览器打开。推荐使用 Edge 或 Chrome，并保持硬件加速开启。本机已有 Node.js，启动器会自动寻找，不需要安装依赖。所有页面、三维库、声音代码都在本地，运行时不依赖互联网。

- 启动：点击「启动引擎」，或按 I。第一次点火会启用声音；右上角可以静音。
- 油门：按住 W，或拖动「油门保持」。S 刹车，A / D 转向，C 离合，Q / E 换挡，R 在试车场复位。
- 引擎：保留五种快速预设，新增来自两份手机备份的 170 条参数库，可搜索车型或发动机。168 条可在当前简化模型运行；W32 和 1000 缸两条极限自定义配置保留数据但限制互动展示。切换时车辆与加速计时复位。
- 三维：鼠标拖动旋转、滚轮缩放。「半剖 / 完整」切换外壳显示；「慢动作」只影响三维机械动画。二维剖面颜色与各缸点火相位是等间隔示意，不表示原厂点火顺序。未建模的机油压力显示为横线。
- 试车场：点击顶部「试车场」，可自由直线驾驶；点击「400 米起跑」，倒计时结束后按住 W。会记录用时、冲线车速、0–100 km/h，并与当前配置的默认调校模拟对手比较。手机备份为手动挡，Q / E 换挡；想自动换挡可点击「手动挡」切换。
- 调校：增压、红线、点火修正、车重影响动力与加速；排气声线改变合成声音。「保存调校」保存在本地浏览器，也可导出或导入 JSON。不同浏览器的本地存档分开。
- 手机 JSON：直接点「导入调校」，选择原 App 的 noi-box-backup 格式文件即可读取当前 draft；不需要先手动转换。支持最大 8 MB。左侧「文件 1 / 文件 2」可快速切换内置的两次导出草稿；导入新备份后，参数库切换为该备份内容。
- 精度和来源：保留缸径、行程、压缩比、怠速、红线、增压形式和车辆原始数值。采用各自的逐挡齿比、终传、轮胎周长、车重、风阻、传动效率和抓地系数；不再固定为六挡。「查看来源参数」可查看已使用和保留的数据。
- 显示边界：三维为归一化结构示意。转子配置不使用往复式活塞冒充，当前展示待补提示。55 个声音与控制设置可查看，但尚未全部映射到合成器。
- 关闭：关掉页面即可停止三维与声音。后台本地服务仍在；需要停止时，用 PowerShell 运行 Stop-EngineLab.ps1。它只会关闭身份匹配的本应用 Node 进程。

服务只监听本机 `127.0.0.1:4328`。再次打开启动器会复用已有服务。启动失败时查看 `.runtime/server-error.log`。

## 与手机原作的关系

参考的是用户确认的《引擎模拟器》，App Store id6818613440，开发者歆晟 魏。此版本按公开功能与用户录屏独立编写，并读取两份调校备份。未取得、解密或反编译 iOS 安装包，没有原作代码、模型或预切音频颗粒；1.2 版按录屏致谢所列来源，取得相同公开录音并自行切粒，署名及改动见「音频素材与许可.md」。它不是官方 Windows 版，尚未实现原作全部界面、多赛道、漂移和其他完整功能。

动力学、调校、温度、健康和音频均采用简化娱乐模型；功率、扭矩等读数为该模型的计算结果，不代表某台真实车辆规格。三维展示是程序化机械示意。

手机参数版使用新的浏览器存档键，保留旧版本存档不删除。旧版的电脑版 JSON 调校文件仍可导入。
